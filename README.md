# Todo List 📝

A simple and responsive Todo List web application built using **HTML, CSS, and JavaScript**.
check this out here : https://himanshu-grow.github.io/To-do-List/

## Features

- Add new tasks
- Add due dates
- Remove individual tasks
- Delete all tasks
- Tasks are saved using **Local Storage**
- Data remains after refreshing the page
- Responsive design
- Glassmorphism UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
